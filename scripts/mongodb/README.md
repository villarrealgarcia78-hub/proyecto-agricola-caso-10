# MongoDB: implementación pendiente

En esta carpeta prepararé el archivo `caso_10_funcionalidad.js` con las instrucciones de MongoDB para la Parte II. El archivo todavía no existe y no se han ejecutado operaciones en MongoDB.

Crearé la colección `observaciones_labor` para agrupar las observaciones de campo. Agregaré al menos tres registros de prueba, llamados documentos, con datos ficticios y coherentes.

Probaré cómo agregar, consultar y modificar documentos, y comprobaré los resultados. Incluiré una consulta con filtro y otra que use un dato agrupado dentro de una observación.

Para probar la eliminación, agregaré un documento adicional. Eliminaré solo ese documento, comprobaré que ya no exista y conservaré al menos tres documentos al terminar.

También comprobaré que las referencias a labores o ciclos correspondan a registros existentes en SQL Server.

El [documento de MongoDB](../../documentacion/mongodb.md) explica el alcance previsto. Después de probar el archivo, añadiré las versiones utilizadas, los comandos de ejecución y los resultados que obtenga.
